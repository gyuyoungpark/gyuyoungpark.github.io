# 그림 1 — 원자핵으로의 운동량 전달과 전자 사이의 운동량 교환

왼쪽에서는 전자가 양전하를 띤 원자핵의 전기적 인력으로 휘어지며 원자핵에 운동량을 전달한다. 오른쪽에서는 두 전자가 서로 밀어내며 운동량을 주고받지만, 두 전자의 총운동량은 유지된다. 아래의 **청록색 화살표**는 산란 전후의 총 전자 운동량을 같은 축척으로 비교한다. 왼쪽의 **주황색 화살표**는 원자핵이 받아가는 운동량이며, 산란 후 전자의 운동량에 더하면 산란 전 운동량과 같아진다. 주황색은 전자 자신의 운동량 변화와는 반대 방향이다.

이 그림의 무거운 원자핵 근사에서는 전자의 운동량 **크기**는 유지되지만, 처음 진행하던 방향의 성분은 줄어든다. 따라서 왼쪽을 “전자 운동량의 크기가 줄어드는 그림”으로 읽으면 안 된다. 전자–전자 산란에서는 개별 운동량이 변해도 두 전자의 벡터 합은 그대로다.

## 표현과 가정

- 좌우 순서는 원자핵 산란 → 전자–전자 산란이다. 썸네일의 청록색, 옅은 배경, 단순한 전하 표시를 사용했다.
- 위쪽 궤적은 고전적인 두 입자 Coulomb 모형의 해석해로 계산했다. 주어진 물질의 실제 측정 결과나 양자 파동함수는 아니다.
- 왼쪽의 원자핵은 전자보다 매우 무겁다고 가정해 궤적 계산에서 위치를 고정했다. 이는 핵 질량을 무한히 크게 취하는 극한이다. 작은 반동 에너지는 무시하지만, 전달받는 운동량은 아래 주황색 벡터에 남겼다. 유한한 질량의 자유 원자핵까지 정확히 다루면 핵이 반동 운동에너지를 얻으므로 전자의 운동량 크기도 조금 줄어든다.
- 전자와 핵이 딱딱한 구슬처럼 접촉하는 그림이 아니다. 입자 기호의 크기는 실제 크기를 뜻하지 않는다.
- 오른쪽 두 전자 표시는 같은 시각의 위치다. 상대 좌표에서의 반발 궤도에 질량중심의 등속 운동을 더했다. 산란 후 한 전자는 더 빠르게, 다른 전자는 더 느리게 진행한다.
- 아래 벡터는 상호작용에서 충분히 멀리 떨어진 산란 전후의 **점근 운동량**이다. 유한한 길이로 잘라 그린 위쪽 궤적 끝점의 순간 운동량과 같다는 뜻은 아니다. 위쪽 궤적의 화살촉은 진행 방향만 표시한다.
- 아래의 모든 운동량 벡터는 `58 px / 운동량 단위`라는 하나의 축척을 사용한다. 왼쪽은 한 전자, 오른쪽은 두 전자의 합을 비교하므로 오른쪽 전체 운동량이 더 크다.
- 옅고 넓은 선은 궤적을 읽기 위한 시각적 보조선이다. 유한한 상호작용 범위, 불확실성 또는 전자 밀도를 나타내지 않는다.
- 고체에서는 완전한 주기 격자 자체를 무작위 산란원으로 취급할 수 없다. 왼쪽은 국소적인 양전하 중심으로 운동량이 전달되는 원리를 보여주는 단순화다.

## 벡터 값

- 원자핵 산란: `p_in = (2, 0)`, `p_out = (1, √3)`, `ΔP_nucleus = (1, −√3)`. 따라서 `p_in = p_out + ΔP_nucleus`. 전자의 변화는 `Δp_electron = p_out − p_in = (−1, √3) = −ΔP_nucleus`다. 전자의 운동량 크기는 둘 다 2이며, 흐름 방향인 x 성분은 2에서 1로 줄어든다.
- 전자–전자 산란: 산란 전 `(2, 1), (2, −1)`, 산란 후 `(3, 0), (1, 0)`. 총운동량은 모두 `(4, 0)`이며 같은 질량을 가정한 운동에너지도 보존된다.
