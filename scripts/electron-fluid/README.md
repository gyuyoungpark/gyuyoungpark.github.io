# Electron-fluid column figures

첨부한 제작 지시를 따라 Python으로 직접 만든 그림입니다. 생성형 이미지 도구는 사용하지 않았습니다. 본문 그림만 교체하며 기존 썸네일은 유지합니다.

- `figure-1.svg` … `figure-5.svg`: 확대 가능한 벡터 원본
- `figure-1.png` … `figure-5.png`: 3200 × 1800 PNG
- `make_figures.py`: 다섯 그림의 배치·수식·라벨·곡선 제작 코드
- `solve_flow.py`: 그림 4의 유한요소 계산 및 검증 코드
- `flow-data/`: 비교한 모든 계산의 원시 데이터와 검증 JSON
- `analytic-validation.json`: 그림 1·2의 수치 검사
- `figure-brief.txt`: 사용자가 제공한 원본 프롬프트와 후속 제작 지시

## 재실행

Python 3.12에서 다음 명령을 실행합니다. 유선 데이터가 동봉되어 있으므로 그림만 다시 만들 때는 마지막 명령만 실행하면 됩니다.

```sh
python -m pip install -r requirements.txt
python solve_flow.py 0,0.4,1,2 0.09
python solve_flow.py 0,0.4,1 0.045
python solve_flow.py 0,0.4,1 0.0225
python make_figures.py
```

## 그림의 성격

1. **Schematic**: 지정한 운동량 벡터를 같은 축척으로 그렸습니다. 전후 합의 오차는 0이고, 오른쪽 패널의 산란 전후 속력 차이는 4.44e-16입니다. 주황 화살표는 `p_in − p_out`입니다.
2. **Analytic model**: `s=y/W`, `f(s)=1−4s²`를 계산했습니다. 벽의 값 0, 중앙의 값 1, 비음수성을 만족하며 대칭 오차는 3.33e-16입니다. 1,001점 사다리꼴 적분 평균은 0.666666, 정확한 2/3과의 오차는 6.67e-7로 허용오차 1e-6 이내입니다. 채널 화살표 길이도 이 함수로 계산했습니다.
3. **Schematic**: 길이척도 관계를 설명하는 영역도이며 상도나 실험 자료가 아닙니다. 점성 영역은 포물선, 넓은 채널은 내부 완화를 포함하는 cosh 형태로 화살표를 배치했습니다. 탄도 궤적은 설명용 도식입니다.
4. **Numerical model**: 아래의 단순화한 정상상태 모델을 실제 계산했습니다. 원하는 유선을 손으로 지정하지 않았습니다.
5. **Schematic**: 흐름 역학과 전자 가열의 두 경로입니다. 채널 폭은 매끄러운 양의 함수로 정의했으며, 열화상·실험 곡선·임계 전압을 만들지 않았습니다.

## 그림 4: 모델과 경계조건

무차원 방정식:

`j − Dν² ∇²j = −σ₀∇φ`, `∇·j = 0`.

균일한 운반자 밀도, `σ₀=1`, `Dν=0.25`, 주 채널 폭 `W=1`, 길이 `L=10`을 사용했습니다. 자기장·가열·대류 비선형성을 제외했습니다. 고체 벽은 `j=0`인 비투과·no-slip 조건입니다. 직선 채널은 `−5≤x≤5`, `0≤y≤1`이며, 원형 곁방은 채널 윗벽에 열린 원호 형태로 연결됩니다.

입구 폭은 `a=1.5R`, 원 중심은 `(0, 1+sqrt(R²−(a/2)²))`입니다. `R=0.4, 1, 2`를 비교했습니다. 그림에는 `R=0.4`와 `R=1`을 같은 공간 축척으로 표시했습니다. `R=0`은 직선 채널 검증용입니다.

유입·유출 접촉부에는 다음의 완전 발달한 전류 프로파일을 지정하고 수직 전류는 0으로 둡니다.

`j_x(y) = [1−cosh((y−1/2)/Dν)/cosh(1/(2Dν))] / [1−1/cosh(1/(2Dν))]`.

두 접촉부의 이산 유량을 정확히 맞추기 위해 출구 프로파일에 작은 보정 계수를 곱합니다. 최종 두 형상의 보정은 1에서 3.46e-9 이내입니다. 접촉부 전위를 추가로 지정하지 않았습니다. 압력 역할을 하는 전위 φ는 왼쪽 아래 한 자유도에서 0으로 고정해 기준만 정했습니다.

삼각형 Taylor–Hood 요소(P2 전류, P1 전위), 4차 적분, 직접 희소 선형 풀이를 사용했습니다. 압력 페널티는 넣지 않았습니다. 채널과 곁방의 곡선 경계는 세분화된 선분으로 근사합니다.

전류 계산 후 `−∇²ψ = ∂x j_y − ∂y j_x`를 풀어 흐름함수를 복원했습니다. 아랫벽은 ψ=0, 윗벽·곁방 벽은 ψ=Q, 접촉부는 위 프로파일의 적분으로 정했습니다. 그림은 ψ의 등고선이며 방향은 독립적으로 계산한 FEM 전류로 확인했습니다. 등고선 간격이 일정하지 않으므로 선 밀도를 전류 크기로 읽으면 안 됩니다.

## 그림 4: 검증 결과와 한계

대표 요소 길이 `h=0.09, 0.045, 0.0225`로 세 단계 계산했습니다.

| 검사 | 작은 곁방 R=0.4, 최종 격자 | 큰 곁방 R=1, 최종 격자 |
|---|---:|---:|
| 삼각형 수 | 65,368 | 80,185 |
| 전류·전위 자유도 수 | 297,164 | 364,198 |
| 약형 연속방정식 잔차 최대값 | 7.53e-15 | 5.09e-15 |
| 네 단면의 적분 유량 상대 차이 | 5.91e-8 | 4.23e-8 |
| 고체 벽 전류 최대값 | 0 | 0 |
| 복원한 ψ의 전류와 FEM 전류의 상대 L2 차이 | 3.06e-4 | 4.58e-4 |
| `||div j||₂ / ||∇j||₂` | 1.29% | 2.39% |

직선 채널에서 해석 프로파일의 최대 오차는 격자를 좁히면서 `2.26e-4 → 4.74e-5 → 6.37e-6`으로 줄었습니다. 벽 전류 0은 부과한 경계조건의 이행 검사이며 독립적인 실험 검증은 아닙니다. 연속방정식은 약형으로 풀리므로 점별 발산이 정확히 0은 아닙니다. 특히 입구의 날카로운 모서리에 오차가 집중됩니다.

작은 곁방에서는 윗벽 값 Q를 넘는 ψ의 내부 최대값과 닫힌 등고선을 세 격자 모두에서 확인했습니다. `max(ψ)−Q`는 `0.003611 → 0.003942 → 0.004120`으로 변했으며, 마지막 두 값의 상대 차이는 약 4.3%입니다. 주 순환의 존재와 반시계 방향은 유지되지만 그 강도를 높은 정밀도로 확정한 계산은 아닙니다.

큰 곁방에서는 주된 흐름이 곁방으로 들어갔다 나오는 열린 경로입니다. 가장 촘촘한 격자에서는 입구 모서리 근처에 ψ 초과량 약 `7.08e-6`의 아주 작은 닫힌 영역 2개가 나타났습니다. 이전 격자에서는 확인되지 않았으므로 이 미세한 순환의 물리적 존재나 강도는 확정하지 않았습니다. 이를 숨기거나 유선을 조작하지 않았고, 그림 라벨을 **Open cavity flow**로 정했습니다. 따라서 ‘닫힌 소용돌이가 완전히 없다’는 주장을 하지 않습니다.

특정 그래핀 실험을 재현하거나 보편적인 임계 입구 폭을 구한 결과가 아닙니다. 큰 곁방의 미세한 모서리 순환, 모서리 특이성 및 점별 발산 오차는 추가 국소 격자 세분화가 필요한 한계로 남아 있습니다.
